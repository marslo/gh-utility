# gh-utility
shared libs for gh-ops and gh-new

# show case

```bash
$ gh new -- -<TAB>
--assignee            --base                --body                --body-file
--dry-run             --editor              --fill                --fill-first
--fill-verbose        --head                --milestone           --no-maintainer-edit
--project             --recover             --repo                --reviewer
--template            --title               --web

$ gh ops --squash -- -<TAB>
--admin              --author-email       --auto               --body               --body-file          --delete-branch      --disable-auto
--match-head-commit  --merge              --rebase             --squash             --subject

$ gh ops --approve -- -<TAB>
--approve          --body             --body-file        --comment          --request-changes
```
